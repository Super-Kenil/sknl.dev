I've been making small browser games lately, with a focus on multiplayer, and they needed a home. This is it: a shelf where every game opens in a click, no installs, no accounts. Brawlers, breakout cabinets, chess, physics toys and a few WebGPU tech demos.

Each game is its own little project, bundled into a static site and framed in a viewer with fullscreen. The shelf has search, a poster grid or compact list, and a device filter so phones only see what actually plays on a phone.

The games aren't open source, but they're all free to play.
