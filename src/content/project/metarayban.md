A browser tool that injects Ray-Ban Meta Smart Glasses hardware profile metadata into any photo. It patches JPEG EXIF, XMP, Display P3 ICC, and AROT headers client-side using binary manipulation.

When uploaded to Instagram Stories, Instagram detects the metadata and unlocks the interactive 3D Spin View tilt effect with the 'Made with Ray-Ban Meta' badge. 100% private and runs entirely in your browser.
