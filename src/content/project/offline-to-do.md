A todo app that works completely offline. No servers, no accounts, no sync issues. Your data lives in your browser using SQLite (via sql.js).

Built this as a PWA, so you can install it on your phone or desktop and use it without internet. The data persists in IndexedDB, so it survives browser restarts.

Added some AI features to help with task organization and reminders. It's basically my personal task manager that I decided to open source. Privacy-first, no data leaves your device.
