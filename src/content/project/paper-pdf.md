paper pdf is a privacy-first PDF toolkit built for the browser. Every tool runs locally in the user's browser, so files never need to be uploaded to a server.

It includes 32 tools for merging, splitting, compressing, converting, OCR, editing, watermarking, signing, and protecting PDFs—without signup or cloud storage.

The project is built with React and TypeScript, with a focus on fast local processing, simple workflows, and a polished document-editing experience.
